# Personaliza Claude Code con 5 mods y crea los tuyos

17/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN8aL9sK8/)

## De qué va

Descubre cinco mods para Claude Code que mejoran la interfaz y la gestión del contexto, y aprende a crear tus propios mods personalizados.

## Ideas

- Utiliza mods para visualizar el uso del contexto y la caché.
- Integra mods que repinten las respuestas con tablas y gráficos.
- Crea mods para monitorizar el flujo de agentes en tiempo real.
- Desarrolla mods personalizados para adaptar Claude Code a tu flujo de trabajo.
