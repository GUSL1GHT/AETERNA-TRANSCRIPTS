## De qué va

Agent Rules Books es una colección de skills gratuitas inspiradas en 14 libros clásicos de programación, diseñadas para mejorar la calidad del código generado por IA, haciéndolo más legible y mantenible.

## Ideas

- Instalar skills específicas de libros de programación para mejorar el código de IA.
- Utilizar diferentes tamaños de skills (full, mini, nano) para optimizar el uso del contexto de la IA.
- Aplicar reglas de 'Clean Code' para refactorizar funciones confusas en la IA.
