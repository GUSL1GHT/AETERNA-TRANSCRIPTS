# Claude Code Setup, el plugin oficial que te dice qué automatizar

15/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85Xgoo1/)

## De qué va

Presenta Claude Code Setup, un plugin oficial y gratuito de Anthropic que revisa tu proyecto y te recomienda qué automatizar: conectores, skills, acciones automáticas y revisores. Solo propone; no cambia nada hasta que se lo pides.

## Ideas

- Instalarlo con `/plugin install claude-code-setup@claude-plugins-official` y pedirle «Recomiéndame automatizaciones para este proyecto».
- Usarlo en un proyecto para descubrir qué conectores, skills o revisores le faltan, y elegir solo los que interesen.

## Lo que dice el vídeo

Claude Code te dice qué automatizar en tu proyecto con un plugin oficial y gratis. Se llama Claude Code Setup y es de Anthropic. Mira tu proyecto y te recomienda las una o dos mejores de cada tipo: conectores con otras apps, skills, acciones automáticas y revisores especializados.

Paso uno: en Claude Code escribes este comando y eliges instalarlo. Paso dos: le pides «Recomiéndame automatizaciones para este proyecto». Paso tres: eliges las que quieras y le dices que las monte. Solo mira, no cambia nada hasta que tú se lo pidas.

Guárdalo. Te dejo la guía gratis con el comando y las frases para pedírselo. La dirección está en mi perfil. La IA cambia cada semana. Síguenos para no quedarte atrás.
