# Claude controla tus apps y trabaja en varias sesiones a la vez

15/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85bbWEq/)

## De qué va

Se presenta agent-desktop, una herramienta de Vercel que permite a Claude ejecutar aplicaciones en tu ordenador, realizar tareas complejas en paralelo y automatizar flujos de trabajo sin intervención manual.

## Ideas

- Automatizar la transferencia de datos entre aplicaciones (PDF a hoja de cálculo).
- Ejecutar múltiples instancias de Claude para tareas simultáneas.
- Delegar tareas repetitivas a Claude para aumentar la productividad.
- Utilizar prompts personalizados para adaptar agent-desktop a casos de uso específicos.
