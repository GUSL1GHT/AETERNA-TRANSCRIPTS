## De qué va

Descubre ocho modificaciones que mejoran la experiencia de usuario y la eficiencia al trabajar con Claude Code, incluyendo control de agentes, gestión de contexto y seguridad.

## Ideas

- Instalar 'Mission Control' para visualizar agentes, tareas y herramientas en Claude Code.
- Utilizar 'Context Keeper' para guardar el progreso de la sesión, decisiones clave y archivos modificados.
- Implementar 'Usage Meter' para monitorizar el consumo de tiempo y los límites de Claude Code.
- Probar 'Blast Radius' para detectar y prevenir acciones potencialmente peligrosas en archivos.

## Lo que dice el vídeo

Desde que Claude Code ha lanzado los mods, han empezado a aparecer un montón de modificaciones para solucionar algunas de las limitaciones más habituales cuando trabajamos con Claude durante horas. Y estos son ocho que realmente merece la pena probar.

El primero es Mission Control, que añade un panel donde podemos ver el agente que está trabajando, los subagentes, las tareas que está haciendo cada uno y las diferentes herramientas o comandos que van ejecutando.

El segundo es Context Keeper, que nos permite crear checkpoints donde se guarda el objetivo de la sesión, las decisiones importantes, los archivos que estamos modificando y las tareas que todavía quedan pendientes.

El tercero es Usage Meter, que añade directamente dentro de Claude Code cuánto hemos consumido de nuestro límite de 5 horas y del límite semanal, además de mostrarnos cuánto margen nos queda y, por supuesto, cuándo se reinicia.

El cuarto es Blast Radius, que detecta acciones potencialmente peligrosas y, antes de ejecutarlas, nos enseña qué archivos podrían verse afectados para decidir si queremos continuar o cancelar.

El quinto es Reflect, que detecta correcciones que hacemos constantemente a Claude y nos permite guardarlas como reglas permanentes para que se tengan en cuenta en futuras sesiones.

El sexto es Replay Theater, que nos permite reproducir uno por uno todos los cambios que Claude ha realizado durante una tarea concreta y revisar en todo momento qué archivos ha modificado y qué ha cambiado dentro de ellos.

El séptimo es Next Steps, que analiza dónde nos encontramos después de terminar una tarea y automáticamente nos propone una serie de próximas acciones que tendría sentido realizar para seguir avanzando con el proyecto.

Y el octavo es Token Weather, que añade un pequeño indicador visual para mostrarnos qué porcentaje de la ventana de contexto estamos utilizando y cuánto nos queda para que se empiece a llenar demasiado.

Y aunque los ocho pueden ser extremadamente útiles, si solamente pudiera quedarme con tres, elegiría Mission Control, Context Keeper y Blast Radius: para controlar mejor los agentes, conservar el contexto y añadir una capa extra de seguridad.
