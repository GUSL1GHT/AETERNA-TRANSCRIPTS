## De qué va

El vídeo explica cómo usar la skill /claude-api prompt-audit de Claude Code para revisar y optimizar prompts antiguos, asegurando que no limiten las capacidades de los modelos de IA más recientes. La herramienta genera un informe y un diff propuesto para su aprobación.

## Ideas

- Revisar prompts antiguos con /claude-api prompt-audit.
- Utilizar /claude-api migrate para actualizar ajustes de API y modelos.
- Aprobar cambios propuestos por la herramienta solo después de entenderlos.
- Probar los resultados con casos reales antes de cambiar de modelo.
