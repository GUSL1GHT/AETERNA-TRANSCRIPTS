## De qué va

Presentación de cinco complementos para Claude Code, incluyendo Playwright, Supabase, Strix, SkillUI y Context7, para mejorar las pruebas, gestión de datos, seguridad, diseño y documentación antes de publicar una aplicación.

## Ideas

- Instala Playwright para que Claude Code pruebe tu web automáticamente como un usuario real.
- Utiliza Supabase y Context7 para conectar bases de datos y mantener la documentación actualizada.
- Emplea Strix y SkillUI para realizar análisis de seguridad y extraer diseños de referencia.

> 5 complementos que deberías instalar en Claude Code antes de publicar una web o una app. 1. PLAYWRIGHT Sirve para que Claude pueda abrir tu web y probarla como un usuario real. Cómo instalarlo: Abre Claude Code y pega esto: “Instálame el MCP de Playwright en Claude Code. Es el oficial de Microsoft, el paquete npm @playwright/mcp. Ejecuta tú el comando, explícame cada permiso que me pidas antes de que lo acepte y avísame cuando tenga que reiniciar.” Acepta los permisos que te pida y, cuando termine, cierra y vuelve a abrir Claude Code. 2. SUPABASE Conecta Claude Code con tu base de datos. Cómo instalarlo: Primero crea una cuenta gratuita en Supabase. Después ve en Claude a Ajustes → Conectores → + → Añadir conector personalizado. Pega esta URL: https://mcp.supabase.com/mcp Pulsa Añadir e inicia sesión en Supabase cuando se abra el navegador. También puedes pedírselo directamente a Claude Code: “Añade a Claude Code el MCP remoto de Supabase, https://mcp.supabase.com/mcp por HTTP. Déjalo en modo solo lectura si se puede y guíame en el inicio de sesión.” 3. STRIX Sirve para analizar tu app buscando vulnerabilidades de seguridad. Cómo instalarlo: Ten Docker abierto y pega esto en Claude Code: “Quiero instalar Strix (github.com/usestrix/strix), la herramienta de pentesting con IA. Instálalo con pipx desde el paquete strix-agent, comprueba antes si tengo Docker y Python funcionando, y si me falta algo dime exactamente qué descargar. Cuando esté, lánzalo contra la carpeta de este proyecto y explícame el informe en lenguaje llano.” Cuando te pida la clave de API, introdúcela tú. El análisis consume API y puede tener coste. 4. SKILLUI Sirve para extraer el diseño de una web y usarlo como referencia. Cómo instalarlo: Abre Claude Code y pega: “Instálame SkillUI (github.com/amaancoderx/npxskillui, paquete npm skillui) de forma global. Comprueba antes si tengo Node.js 18 o superior y dime qué descargar si no. Luego extrae el diseño de https://notion.so y déjame la carpeta lista para trabajar.” Puedes cambiar https://notion.so por la web cuyo diseño quieras analizar. 5. CONTEXT7 Le da a Claude documentación actualizada para trabajar con las versiones más recientes. Cómo instalarlo: En Claude ve a Ajustes → Conectores → + → Añadir conector personalizado. Pega: https://mcp.context7.com/mcp Pulsa Añadir y listo. También puedes pedírselo a Claude Code: “Añádeme Context7 a Claude Code: el MCP remoto https://mcp.context7.com/mcp por HTTP. Compruébalo y dime cómo pedirte que lo uses a partir de ahora.” IMPORTANTE: cuando instales cualquiera de los que van por Claude Code, cierra Claude Code completamente y vuelve a abrirlo.
