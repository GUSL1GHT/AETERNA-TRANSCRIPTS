# Cinco plugins para potenciar tu programación con IA

24/10/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN8D2qYR3/)

## De qué va

Descubre cinco plugins esenciales que mejorarán tu experiencia de desarrollo con herramientas de IA como Claude Code y Codex, desde automatizar pruebas hasta gestionar bases de datos y estilos de diseño.

## Ideas

- Automatizar la detección de errores y capturas de pantalla en el desarrollo web con Playwright CLI.
- Simplificar la gestión de bases de datos para aplicaciones directamente desde la terminal con el plugin de Supabase.
- Identificar y corregir vulnerabilidades de seguridad en aplicaciones con Strix.
- Extraer sistemas de diseño de sitios web existentes para replicar estilos en nuevos proyectos con skillUI.
- Mantener actualizadas las librerías y dependencias de tus proyectos utilizando Context7.

## Lo que dice el vídeo

Si programas con Claude Code o con Codex, estos cinco plugins te ahorran los disgustos.

El primero es Playwright CLI. Tu IA puede abrir un navegador, hacer capturas de lo que acaba de construir y detectar los errores antes de que tú los veas.

El segundo es el plugin de Supabase. Construyes y gestionas bases de datos completas para tus apps sin salir del terminal.

El tercero es Strix. Ataca tu app como lo haría un hacker de verdad. Encuentra los agujeros de seguridad que se te han pasado y te los arregla.

El cuarto es skillUI. Lo apuntas a cualquier web que te guste y te extrae todo su sistema de diseño en un archivo Markdown. Tu IA construye el proyecto con ese mismo estilo.

Y el quinto es Context7. Le da a tu asistente las versiones más recientes de todas las librerías y dependencias. Nunca más programar sobre una versión desactualizada.

Si no quieres perderte ninguna noticia de este estilo, síguenos para no perderte las próximas.
