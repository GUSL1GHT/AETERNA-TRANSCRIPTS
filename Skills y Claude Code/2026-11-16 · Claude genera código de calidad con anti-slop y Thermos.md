# Claude genera código de calidad con anti-slop y Thermos

16/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85sunFq/)

## De qué va

Este vídeo explica cómo mejorar la calidad del código generado por Claude utilizando dos herramientas: anti-slop, que aplica reglas para detectar errores comunes, y Thermos, que realiza revisiones de calidad más profundas.

## Ideas

- Implementar anti-slop para detectar errores comunes en el código generado por IA.
- Usar Thermos para revisiones de calidad automáticas y detener archivos de código excesivamente largos.
- Configurar árbitros para que la IA no pueda cruzar límites de calidad predefinidos.
- Solicitar guías detalladas para implementar estas herramientas en proyectos existentes.
