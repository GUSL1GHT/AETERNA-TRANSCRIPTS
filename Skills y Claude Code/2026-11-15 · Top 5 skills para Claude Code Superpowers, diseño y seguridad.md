# Top 5 skills para Claude Code Superpowers, diseño y seguridad

15/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85bpxJr/)

## De qué va

Este vídeo presenta las 5 mejores skills para Claude Code: Superpowers, Frontend-design, Webapp-testing, Security-audit y Skill-creator, explicando qué son y cómo instalarlas.

## Ideas

- Instalar skills de fuentes de confianza para evitar riesgos de seguridad.
- Utilizar la skill Superpowers para imponer un método de trabajo estructurado.
- Explorar la skill Skill-creator para desarrollar y probar tus propias skills personalizadas.
- Integrar skills de gestión de nube como las de CubePath para optimizar flujos de trabajo.

## Lo que dice el vídeo

Cinco skills que llevan Claude Code a otro nivel.

¿Qué es una skill?
Una skill es una carpeta con instrucciones, y a veces scripts, que Claude carga solo cuando le hace falta.

Uno. Superpowers.
Le impone un método: primero el plan, luego los tests, y depuración paso a paso.

Dos. Frontend-design, de Anthropic.
Para que tus interfaces no tengan esa cara genérica de IA.

Tres. Webapp-testing.
Claude abre tu web con Playwright, la prueba y revisa capturas y errores.

Cuatro: Security-audit, de Cloudflare.
Busca vulnerabilidades en tu código, y otros agentes intentan desmentirlas.

Cinco: Skill-creator.
Para crear tus propias skills y comprobar que funcionan.

Se instalan con barra plugin o con NPX skills add. Eso sí: solo de fuentes de confianza, porque pueden ejecutar código.

Y CubePath tiene sus propias skills para gestionar tu nube desde Claude Code.
