# Cinco complementos esenciales para potenciar Claude Code

15/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85pxSVv/)

## De qué va

Se presentan cinco complementos para Claude Code: Claude Mem para mantener contexto, Find Skills para buscar habilidades, Any Doc para convertir documentos a Markdown, Claude Code Setup para recomendar herramientas y Agent Skills para tareas de programación.

## Ideas

- Utilizar Claude Mem para mantener el contexto entre sesiones de programación.
- Emplear Find Skills para descubrir y facilitar la instalación de habilidades útiles.
- Convertir documentos de Office a Markdown con Any Doc para que Claude los lea.
- Aprovechar Claude Code Setup y Agent Skills para automatizar y mejorar el desarrollo de código.

## Lo que dice el vídeo

Si usas Claude Code, hay cinco complementos que merece la pena conocer. Uno incluso analiza tu proyecto y te recomienda qué herramientas añadir.

El primero es Claude Mem. Guarda contexto entre sesiones para que tengas que repetir menos explicaciones al retomar un proyecto.

El segundo, Find Skills. Le dices qué necesitas hacer y busca habilidades que puedan ayudarte, además de facilitarte la instalación.

El tercero es Any Doc. Convierte Word, Excel y PowerPoint en Markdown, un formato de texto que Claude puede leer.

El cuarto, Claude Code Setup. Revisa tu proyecto y recomienda habilidades, automatizaciones y conexiones con otras herramientas.

Y el quinto, Agent Skills. Reúne habilidades para planificar, programar, hacer pruebas y revisar el código.

Yo empezaría por el que resuelva un problema que ya tengas. Si trabajas con documentos, por ejemplo, miraría Any Doc.
