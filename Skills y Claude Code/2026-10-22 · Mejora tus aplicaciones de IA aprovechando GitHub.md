## De qué va

Utiliza GitHub para encontrar repositorios de código abierto con miles de estrellas y extrae ideas para acelerar el desarrollo de tus aplicaciones de IA.

## Ideas

- Pedir a la IA que busque en GitHub repositorios de código abierto con más de 1000 estrellas relacionados con la tarea actual.
- Utilizar ideas de repositorios exitosos en lugar de empezar desde cero para diseñar pantallas, animaciones o lógica de funciones en aplicaciones de IA.

## Lo que dice el vídeo

Te voy a dar el truco más simple, un poco tramposo, pero bueno, moralmente aceptable para mejorar cualquier tipo de aplicación que estés creando con IA. Cada vez que le pidas algo a tu IA, dile también esto: que entre en GitHub, que busque repositorios de código abierto con más de 1000 estrellas que tengan que ver con lo que estáis haciendo y que coja ideas de ahí. Esto sirve para cualquier parte de tu aplicación: el diseño de las pantallas, las animaciones, la lógica de alguna función concreta, y también funciona para cualquier tipo de página web o de cualquier otro proyecto que esté montando con IA.

Un aviso: no todo lo que está en abierto se puede usar libremente. Revisa la licencia del repositorio antes de meterlo en algo que vayas a publicar o vender, que ahí es donde la gente se mete en líos sin darse cuenta. Y ahora sígueme para aprender más sobre IA.
