# Potencia Claude: 3 herramientas clave para tu agencia de IA

13/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85jbKuM/)

## De qué va

Descubre tres servidores MCP (Model Context Protocol) para Claude: Perplexity para búsqueda avanzada, Firecrawl para 'scrapear' webs y extraer información de competencia, y Playwright para automatizar acciones en navegadores y apps.

## Ideas

- Integrar Perplexity para mejorar la investigación de Claude, obteniendo información más precisa y completa.
- Utilizar Firecrawl para analizar a la competencia de forma rápida, extrayendo elementos clave como marca, colores y tipografía.
- Aprovechar Playwright para automatizar tareas complejas en Claude, como rellenar formularios o interactuar con aplicaciones sin API.

## Lo que dice el vídeo

Si usas Claude solo con prompts, estás dejando el 90% de su potencial afuera. Te voy a dar tres MCPs que le tienes que conectar ya mismo y son los que nosotros usamos en nuestra agencia de inteligencia artificial. Guarda este vídeo para cuando los vayas a instalar.

MCP 1 de 3: Perplexity. Primero, el más conocido, Perplexity. Le da a Claude acceso directo al motor de búsqueda de Perplexity, uno de los más potentes que hay para investigar lo que tú quieras. Lo vas a usar siempre que necesites buscar información de cualquier sitio web.

MCP 2 de 3: Firecrawl. El segundo, el que más sorprende, Firecrawl. Le da a Claude la capacidad de scrapear y de recorrer cualquier página web de internet. Y aquí viene lo mejor: si tienes competidores, le pasas su página y te extrae la marca completa, los colores, la tipografía, el logo y toda la información de la página que tú quieras. O sea que en un minuto tienes una investigación completa de tu competencia que antes te tomaba días completos.

MCP 3 de 3: Playwright. El tercero, que es mi favorito, se llama Playwright. Este es literalmente Claude usando tu navegador como si fuera una persona. Llena formularios, prueba páginas web y, lo más loco de todo, se puede meter en aplicaciones que no tienen ni API ni MCP. Esto con otra skill no lo puedes hacer. Es como si tuvieras a una persona sentada en tu computadora trabajando por ti.
