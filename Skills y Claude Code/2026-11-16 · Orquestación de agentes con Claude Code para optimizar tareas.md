# Orquestación de agentes con Claude Code para optimizar tareas

16/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN85s7ed6/)

## De qué va

Aprende a orquestar sub-agentes con Claude Code para repartir y ejecutar tareas de forma eficiente, optimizando el uso de modelos y el pago.

## Ideas

- Utilizar Claude Code para crear sub-agentes con modelos Opus o Sonnet.
- Implementar un sistema de workflow para repartir tareas entre sub-agentes.
- Usar el comando /loop para revisar y corregir el trabajo de los sub-agentes.
- Optimizar costos pagando modelos caros solo para tareas de pensamiento y orquestación.

## Lo que dice el vídeo

Hoy aprendes a orquestar con Claude.
Si estás construyendo con Claude, te está costando el doble si no sabes orquestar con él. Hoy vas a aprender cómo orquestar con él sin instalar nada. Vamos a abrir la aplicación de Claude y vamos a la sección de Claude Code.
Si tienes el plan de cien o de doscientos, empezamos con Fable. Y si tienes el plan de veinte, comenzamos con Opus.
Y vamos a vaciarle un documento de todo lo que tenemos que construir hoy. Y le vamos a escribir: "Aquí te va todo lo que tengo que terminar esta semana, no hagas nada, solo lee el documento".
Ahora Claude, entendiendo lo que tienes que hacer, ahora le avientas un prompt que dice así: "Crea sub-agentes usando el modelo de Opus, si tienes la cuenta de cien o de doscientos, o el modelo de Sonnet, si tienes la cuenta de veinte, y reparte la lista de trabajo usando el sistema de workflow".
Claude Code, literalmente te va a dejar escoger el modelo para la tarea que necesitas hacer y cada sub-agente lo que va a hacer. Y tú escoges si esa tarea que tienes que hacer es con Opus o con Sonnet.
Fable o Opus no van a construir, sino van a repartir. Y le van a escribir a cada sub-agente qué hacer, cuándo correr, si tienen que correr cuatro o cinco agentes a la vez.
Y la cereza del pastel, le dices a tu orquestador, sea Opus o Fable, un prompt algo así: "/loop, revisa lo que entregó cada sub-agente y al que no haya cumplido con lo que tenía que hacer, es /goal, regrésalo para que lo corrija con la meta de que esa tarea cumpla con su cometido".
Y eso se va a repetir hasta que el sub-agente cumpla bien con lo que tiene que hacer.
Así que solo vas a pagar el modelo caro para pensar y hacerse cargo, y el volumen pesado lo hacen todos los demás.
Por eso es bueno también tener un documento bien hecho de todo lo que tienes que hacer o quieres construir.
Y si quieres una guía más detallada de cómo puedes comenzar a hacer orquestas de agentes y sub-agentes para ayudarte a hacer lo que tienes pendiente y construir lo que quieres hacer con Claude, comenta: "¿Para qué te gustaría hacer esta orquesta? ¿Qué te pondrías a construir o qué estás construyendo ahorita?" Y te la paso.
Y si te gustó, no olvides seguirme y compartirlo con alguien que lo necesita.
