Validación de modelos

Crear
skill propia · no viene de las transcripciones

Ninguna transcripción trata algoritmos matemáticos. Para ComboLab propongo una skill propia: backtesting sin fuga de datos, calibración (Brier, log-loss, curva de fiabilidad), tamaño de muestra y comparación con la cuota del mercado.

Para: comprobar que las probabilidades que da ComboLab aciertan lo que dicen, no solo que el código funciona.

Descartadas y por qué

  • MCP de Playwright, Firecrawl y Perplexity: el navegador integrado, Claude en Chrome y la búsqueda web ya lo cubren; cada MCP extra carga herramientas en todas las sesiones y dos piden clave de pago.
  • Strix: lanza ataques reales en Docker; security-audit cubre lo mismo con menos riesgo.
  • Free Claude Code, FreeLLMAPI, OmniRoute: tu código y tus claves pasarían por terceros.
  • Graphify, Memanto, claude-mem: duplican Codebase Memory o tu memoria en archivos.
  • Agent Reach, last30days, Humanizer, Stop Slop, Lemo Opuscar, CLI-Anything: no encajan con ninguno de tus proyectos actuales.
  • /watch (vídeos de YouTube): necesita una clave de Gemini; AETERNA ya transcribe vídeos.

Lo que depende de ti

  • Hecho: las 3 skills están en ~/.claude/skills, fijadas al commit revisado (ver ORIGEN.txt de cada una). Aparecen al abrir una sesión nueva.
  • webapp-testing necesita Playwright para Python, que no está instalado: pip install playwright y python -m playwright install chromium (descarga unos 150 MB). Se instala cuando la usemos por primera vez, con tu permiso.
  • Decir si creo la skill de validación de modelos para ComboLab.
  • Las librerías (Scrapling, MarkItDown, VoiceStudio, HyperFrames) se añaden cuando trabajemos en cada proyecto, no ahora.
