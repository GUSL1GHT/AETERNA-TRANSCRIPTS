Paso 1: crear la clave API. Sin interrupciones, vamos a sumergirnos y crear una clave API de Gemini gratuita. Sorprendentemente, es totalmente gratis. Ahora dirígete a tu navegador y escribe Google AI Studio. Busca y abre el enlace oficial de Google.com. Asegúrate de haber iniciado sesión y dirígete al panel de control. Aquí haz clic en crear clave API. Puedes nombrarla como quieras; solo para que sepáis qué clave API es esta, usaré Jarvis versión 3.0.

Espera pacientemente a que cree tu clave API personal. Advertencia: nunca compartas tu clave API con nadie. Copia esta clave y guárdala en un bloc de notas para usarla más tarde.

Paso 2: descargar el código de GitHub. Haz clic en el enlace proporcionado en la descripción. Esta es una IA creada por FatihMakes, la mejor IA personal que he encontrado, con muchas funciones. Ahora haz clic en Mark L2, la última versión creada, y luego haz clic en código y descarga el archivo comprimido como se muestra en pantalla. Localiza la carpeta zip descargada y haz clic derecho sobre ella. Haz clic en extraer todo a cualquier carpeta que desees.

Ahora abre la carpeta extraída con Visual Studio Code. Si no tienes este acceso directo de clic derecho, abre Visual Studio Code y sigue mis pasos. Esto es crucial: a medida que se abre el archivo, pasemos al paso cuatro. Desde aquí tienes que abrir una nueva carpeta y luego asegurarte de abrir la carpeta extraída.

Paso 3: descargar Python. Abre tu navegador y busca «descargar Python» (python download). Abre el sitio web oficial python.org. Haz clic en descargas y selecciona tu sistema operativo. Descarga cualquier versión superior a la 3.11. Yo voy a descargar la 3.13.14. Espera pacientemente a que Python se instale.

Una vez completada la instalación, haz clic izquierdo en el archivo abierto. Haz clic en «Añadir Python.exe a PATH». Este es el paso más importante. Ahora haz clic en «Instalar ahora». La configuración fue exitosa, así que pasemos al siguiente paso. Haz clic en el botón de cerrar.

Paso 4: configuración. Ahora puedes ver todo el código justo delante de ti. Ya casi hemos terminado, solo queda un último paso. Desde la parte superior, abre una nueva terminal. Escribe «py setup.py» y pulsa enter. Si tienes algún tipo de error aquí, no dudes en dejarlo en la sección de comentarios. Esto comenzará a descargar todas las librerías necesarias para tu asistente personal de IA. Espera pacientemente aquí hasta que veas este mensaje verde. Si ves esto en tu pantalla, entonces felicidades.

Ahora has creado con éxito tu propio asistente personal de IA avanzado. Para ejecutarlo, escribe «py main.py» en tu terminal y pulsa enter. Aquí pega la clave API que creaste y guardaste anteriormente. De nuevo, digo que nunca compartas tu clave API con nadie. También selecciona si estás en Windows, Macintosh o Linux. Yo estoy en Windows, así que seleccionaré Windows. Finalmente, inicializa los sistemas y ya estás listo para empezar.

«Hola, señor, son las 21:12 y ahora estoy buscando las noticias principales de hoy.»

Capacidades. Hablemos de las increíbles capacidades de Jarvis 3.0. Palabra clave: Jarvis escucha continuamente «Hey Jarvis» y activa el asistente cuando detecta esa frase. Memoria recuperable: Jarvis recuerda detalles importantes de conversaciones anteriores y los recupera más tarde cuando se lo pides. Voz en tiempo real: Jarvis escucha y responde instantáneamente a través de una conversación de voz natural bidireccional. Control del sistema: la característica más asombrosa, controla tu PC con comandos de voz naturales y muchas más características asombrosas mostradas en la pantalla.
