# 5 repositorios de GitHub para potenciar tu IA

03/11/2026 · TikTok · [Ver el vídeo](https://vm.tiktok.com/ZN8yfJT2H/)

## De qué va

Descubre 5 herramientas de GitHub para facilitar la gestión de datos, el análisis web, la automatización de tareas, la creación de videos y la descarga de contenido multimedia.

## Ideas

- Utiliza MarkItDown para centralizar y procesar información de negocio para IA.
- Integra Firecrawl para que tu IA analice contenido web de forma limpia y estructurada.
- Aprovecha Browser Use para automatizar interacciones web y recolección de datos.
- Explora Remotion para generar videos mediante código, ideal para animaciones o contenido dinámico.
- Emplea Cobalt para descargar videos de plataformas populares sin marcas de agua ni publicidad.
