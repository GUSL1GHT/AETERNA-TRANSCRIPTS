## En pantalla

- Título: "8 proyectos de GitHub que deberías conocer" (Open source, GitHub; herramientas sorprendentes que quizá no conocías). Cuenta @jaime_rp85. Estrellas consultadas el 12/10/2026. Temas: 01 AirPods, 02 Archivos, 03 Agentes, 04 Win 95, 05 Música, 06 Navegador, 07 Procesos, 08 Emails.
- 01 LibrePods, 30,2k estrellas: saca todo el partido a tus AirPods en Android. Cambia entre cancelación y transparencia, mira la batería y usa la detección de oído desde Android o Linux. Si tienes AirPods pero no iPhone, recuperas funciones que normalmente pierdes. Ojo: algunas funciones necesitan root o Xposed; última versión: candidata (rc). `github.com/librepods-org/librepods`
- 02 VERT, 15,6k: convierte +250 formatos sin subir tus archivos (.HEIC a .JPG, .FLAC a .MP3, .DOCX a .PDF en tu dispositivo; .MOV a .MP4 o vídeo: servidor). Imágenes, audio y documentos se convierten en tu propio navegador gracias a WebAssembly. Olvídate de webs de conversión con anuncios que te obligan a subir tus archivos. Ojo: el vídeo se procesa en un servidor, salvo que lo autoalojes. Web: vert.sh. `github.com/VERT-sh/VERT`
- 03 CLI-Anything, 51,3k: enseña a tu agente de IA a usar GIMP, Blender, LibreOffice, OBS Studio, Audacity, Inkscape. Ejemplo: `/cli-anything ./gimp` (analiza el código, diseña los comandos, CLI + tests + JSON). Tu agente analiza el código de una app y le genera comandos, con tests y salida en JSON; un agente trabaja mucho mejor con comandos que haciendo clics en ventanas. Ojo: necesita el código fuente de la app y un agente como Claude Code o Codex. `github.com/HKUDS/CLI-Anything`
- 04 Windows 95, 24,2k: emula Windows 95 completo en JavaScript, dentro de una app; funciona en Windows, macOS y Linux. Trae juegos de DOS y Windows preinstalados y puedes añadir más. Ojo: es una curiosidad, no un sistema para trabajar; sin relación con Microsoft. `github.com/felixrieseberg/windows95`
- 05 Pear Desktop, 33,7k: YouTube Music como app de escritorio, con plugins y temas CSS, para Windows, macOS y Linux. Ojo: no es oficial, no está afiliado a Google ni a YouTube. `github.com/pear-devs/pear-desktop`
- 07 witr, 22,5k: "¿Quién ha lanzado este proceso?". Ejemplo: `witr --port 5000` ("Why It Exists: systemd -> pm2 -> node"; fuente, usuario, PID, inicio). Le das un proceso, un puerto o un contenedor y te enseña quién lo arrancó: systemd, Docker, cron, SSH... Funciona en Linux, macOS, Windows y FreeBSD. Licencia Apache-2.0. Perfecto cuando un puerto está ocupado o algo se inicia solo. `github.com/pranshuparmar/witr`
- 08 Reacher, 10,0k: filtra correos inválidos antes de enviar nada (resultados is_reachable: safe, risky, invalid, unknown; direcciones de ejemplo ficticias). Comprueba sintaxis, servidor, buzón, correos desechables y catch-all sin mandar ningún mensaje. Ojo: da una estimación, no una garantía; necesita el puerto 25 abierto. AGPL-3.0 o licencia comercial. `github.com/reacherhq/check-if-email-exists`
- Chuleta con los 8 repos: 01 LibrePods (AirPods en Android y Linux), 02 VERT (conversor local, +250 formatos), 03 CLI-Anything (apps a comandos para IA), 04 Windows 95, 05 Pear Desktop, 06 PinchTab (un navegador para agentes, `github.com/pinchtab/pinchtab`), 07 witr (por qué corre un proceso), 08 Reacher (verifica emails sin enviar).
