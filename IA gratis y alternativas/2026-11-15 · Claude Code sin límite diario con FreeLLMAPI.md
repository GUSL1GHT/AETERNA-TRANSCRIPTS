## De qué va

Descubre cómo usar Claude Code sin límites diarios ni coste utilizando FreeLLMAPI, una herramienta open source que agrega planes gratuitos de múltiples proveedores de IA.

## Ideas

- Utiliza FreeLLMAPI para evitar límites diarios en Claude Code.
- Integra FreeLLMAPI con Docker para una instalación sencilla.
- Configura modelos de reserva como Gemini o Llama para asegurar continuidad.
